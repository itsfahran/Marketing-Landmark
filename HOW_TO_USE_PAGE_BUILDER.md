# 📖 COMPLETE USER GUIDE - HOW TO USE THE PAGE BUILDER

## 🎯 Quick Overview

The Page Builder lets you create custom pages by:
1. Selecting components (Hero, Scope, Pricing, Process, etc.)
2. Choosing a template for each (SEO, GEO, LOCAL)
3. Filling component data
4. Adding separate items (scope cards, pricing packages, process steps)
5. Publishing the page

---

## 🚀 STEP-BY-STEP GUIDE

### **STEP 1: Navigate to Page Builder**

```
Admin Dashboard → Pages → [+ Create New Page]

OR

Admin Dashboard → Pages → [Edit Page]
```

---

### **STEP 2: Create/Edit Page Settings**

Fill in these fields:

```
┌────────────────────────────────────┐
│ CREATE NEW PAGE                    │
├────────────────────────────────────┤
│                                    │
│ Page Name:                         │
│ [My Business Services Page______]  │
│                                    │
│ Page Slug:                         │
│ [my-business-services_________]   │
│ (Auto-generates from name)         │
│                                    │
│ Status:                            │
│ [Draft ▼]                          │
│  └─ Draft (visible only to you)   │
│  └─ Published (visible to public)  │
│                                    │
│ [Save Page]                        │
└────────────────────────────────────┘
```

**Tips:**
- Page Name: What you'll see in admin
- Page Slug: What appears in the URL (e.g., /my-business-services)
- Start as Draft to test

### **HOW TO ADD SCOPE CARDS**

#### **Step 1: Click "📝 Manage Scope Cards"**

```
In the SCOPE form, click:
[📝 Manage Scope Cards]

A modal will open showing:

┌──────────────────────────────────────────┐
│ Manage Scope Cards (GEO)              [✕]│
├──────────────────────────────────────────┤
│                                          │
│ Existing Cards:                          │

│ │ ☰ 01 | Audit    | [Edit] [Delete]  │ │
│ │ ☰ 02 | Optimization | [E] [Del]   │ │
│ │ ☰ 03 | Visibility | [Edit] [Del]  │ │
│ └──────────────────────────────────────┘ │
│                                          │
│ [+ Add New Card]                         │
│                                          │
└──────────────────────────────────────────┘
```

#### **Step 2: Add New Card**

Click `[+ Add New Card]`:

```
┌──────────────────────────────────────────┐
│ Edit Card                             [✕]│
├──────────────────────────────────────────┤
│                                          │
│ Number:                                  │
│ [04]                                     │
│                                          │
│ Title: *Required                         │
│ [Continuous Improvement______________]  │
│                                          │
│ Description: *Required                   │
│ [We continually monitor, optimize and   │
│  improve your GEO presence to ensure    │
│  sustained growth and visibility]       │
│                                          │
│ Icon Name (e.g., FaFileAlt):             │
│ [FaSync]                                 │
│                                          │
│ Icon Image URL:                          │
│ [https://example.com/icon.png____]      │
│ (Or use icon name OR image URL, not both)│
│                                          │
│ [Save Card]  [Cancel]                    │
│                                          │
└──────────────────────────────────────────┘
```

#### **Step 3: Save Card**

Click `[Save Card]`:
- Card saved to database
- Modal refreshes
- Card appears in list
- Can edit or delete anytime

#### **Step 4: Add More Cards**

Repeat for all cards you need (typically 3-5 cards)

#### **Step 5: Reorder (Optional)**

If you need to change order:
1. Click and hold the ☰ icon
2. Drag card up or down
3. Release to drop
4. Order auto-saves

#### **Step 6: Close Manager**

Click [✕] button to close modal:
```
Back to main form
→ Card count shows: (5 cards added)
```

```

```

#### **Fill Hero Data (2 minutes)**
```
1. Heading: "Best GEO Services"
2. Description: "Get ranked across..."
```

```
1. Heading: "Scope Of GEO"
2. Description: "Our scope is designed..."
3. [📝 Manage Scope Cards] ← Opens manager
   - Add Card 1: Audit
   - Add Card 2: Optimization
   - Add Card 3: Visibility
   - [✕] Close
4. [Save Scope]
```

#### **Fill Pricing Data (5 minutes)**
```
1. Heading: "Pricing Packages"
2. Description: "Choose your plan..."
3. [💰 Manage Pricing Packages] ← Opens manager
   - Add Package 1: Basic (₹59,999)
     └─ Add 20 features
   - Add Package 2: Standard (₹99,999)
     └─ Add 25 features
   - Add Package 3: Premium (₹149,999) ⭐
     └─ Add 30 features
   - [✕] Close
4. [Save Pricing]
```

#### **Fill Process Data (3 minutes)**
```
1. Heading: "How We Work"
2. Description: "Our proven process..."
3. [🔄 Manage Process Steps] ← Opens manager
   - Add Step 1: Website Audit
   - Add Step 2: Keyword Research
   - ... Add Step 8: Maintenance
   - [✕] Close
4. [Save Process]
```

#### **Publish (1 minute)**
```
1. [Publish Page]
2. Page status → Published
3. Visible at: /my-services
```

#### **Total Time: ~15 minutes**

## 💡 **TIPS & TRICKS**

### **Edit After Publishing**
```
Admin → Pages → [Your Page] → [Edit]
↓
Make changes
↓
[Publish] (auto-updates)
↓
Changes appear immediately on public page
```

### **Duplicate Page**
```
Admin → Pages → [Your Page] → [Duplicate]
↓
Creates copy with "-2" in slug
↓
Edit and customize
↓
Publish
```

### **Delete Page**
```
Admin → Pages → [Your Page] → [Delete]
↓
Confirm deletion
↓
Page & all sub-items removed from database
```

### **Reorder Components**
- Click and hold ☰ icon on component
- Drag to new position
- Release
- Auto-saves ordering

### **Change Template**
```
Select Components panel
↓
Click template dropdown for any component
↓
Choose different template (SEO, GEO, LOCAL)
↓
Component styling changes instantly
```

### **Undo Accidental Delete**
```
Currently: No undo feature
Solution: Recreate deleted items (10 min)

Future: Implement soft-delete or recycle bin
```

## 🆘 **TROUBLESHOOTING**

### **"Manage [Component]" button not showing?**
- Enable the component in "Select Components"
- Refresh page
- Try again

### **Can't add more scope cards?**
- Click "Add New Card" button
- Fill title and description
- Click "Save Card"
- If error, check console logs

### **Pricing packages not showing on public page?**
- Verify packages were saved (check in manager)
- Verify page was published
- Refresh public page (Ctrl+Shift+R hard refresh)
- Check browser console for errors

### **Process steps out of order?**
- Drag steps to correct order in manager
- Order auto-saves
- Refresh public page to see changes

### **Data disappeared after publishing?**
- Check if page is actually published (not draft)
- Check database directly
- Contact developer if still missing
